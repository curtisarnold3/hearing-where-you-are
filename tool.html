RUN THE TOOL the same physics as the pictures, on the studio machine

Stand on the map and ask what you would have heard.

You cannot honestly run this backwards, from a wiggle in pitch to a map pin, in one formula. A small error in the wiggle becomes a large error on the ground. The package does the forward problem instead. It puts a pretend microphone on each spot, plays every flight past that spot, and keeps the spot whose pretend recording matches yours.

BEFORE ANY SEARCH

Point this page at the studio.

This page is the window. The arithmetic stays in the dopgeo package, on a machine you reach in a browser. Vercel only serves these pages. A serverless function cannot hold the hear table, ffmpeg, or a terrain file, so the search is not computed here. A database is not in the path either. The audit log is written on the studio machine, next to the job, and it stays there.

Why a token

The page can be on the public web. The search should not be. The studio refuses every run until the shared token matches. A real recording also needs a purpose sentence, which is stored with your name, the time, a hash of the file, and the one-line result.

127.0.0.1 means the computer you are sitting at. This Vercel page cannot see a studio that is running somewhere else. Leave this field blank until the studio has an https address your browser can open.

REHEARSAL · WHAT IS ABOUT TO HAPPEN

Same formulas on both sides of the problem.

  1. A hidden recorder is placed on a rolling fake hillside. Two propeller flights pass it, about 15 minutes apart. The audio is built with the package’s own sound-speed, 343 m/s, about 20 °C.
  2. The fit reads each slide. How far the pitch falls is mostly speed. How sharply it bends is mostly the closest distance. The moment the pitch crosses the engine’s own note is when the sound of the closest point arrives, not when the aircraft was there.
  3. The funnel throws away spots that could not have heard those two passes that far apart, at those speeds, at those distances. Then it throws away spots that should have heard some other aircraft in the quiet gap and did not. Silence is evidence.
  4. The score is not another filter. For each survivor it lays the real curved flight path onto the spectrogram and adds up the brightness under that curve. The hotter spot wins. On this rehearsal the winner should sit on the hidden recorder, 0 m off. That checks the wiring. Wind, a wrong temperature, and a bad clock are absent here, so 0 m is not a field accuracy number.

The one-curve cross-check at the end uses only the first slide plus the known clock. It is weaker, and it usually misses by a few hundred meters. Two slides plus the gap are what pin the spot.
